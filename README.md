# Employee Management System

An employee list. Click Fetch and the table fills with name, gender, department, and salary. Filter by department or gender, and sort the salary from low to high or high to low.

The rows come from a public employee API. Refresh the page and the table starts empty again until you click Fetch.

## How to open

From this folder, run:

```bash
npx --yes serve -l 5000 .
```

This starts a small local server. Then open http://localhost:5000/ .

You can also open `index.html` directly. Fetch needs a network connection.
